This is a plug-in built using the 8.0 .NET Framework.

Running the plug-in requires AutoCAD versions 2025 or above.

To load the plug in, simply run the command "netload"  inside AutoCAD and select the "AirportAppLoader.dll" file from inside the Executable Package.

A tab named "Airport Tools" will load to the toolbar and the tab contains the "Generate Airport" button which will prompt the user for an ICAO code to execute.

PLEASE ENSURE THE .exe FILE STAYS IN THE SAME FOLDER AS THE .dll OR THE PROGRAM WILL THROW A PATH NOT FOUND EXCEPTION.

All outputs will be saved in the "Export" folder to be automatically created under the same directory where the .dll file can be found.
